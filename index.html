My Marketing AI

Voir le site
Next.js API IA (GPT) SaaS / abonnements
Problème Les vendeurs e-commerce passent un temps considérable à rédiger le contenu marketing de chaque produit : descriptions, publicités, emails, argumentaires.
Ce que j'ai construit Un SaaS où il suffit de coller l'URL d'un produit (Amazon, Alibaba, AliExpress) pour générer automatiquement l'ensemble du contenu marketing associé — descriptions, arguments de vente, publicités, emails, up-sell/cross-sell, argumentaires de collaboration influenceurs. Le produit inclut trois formules d'abonnement et les pages légales complètes (CGV, confidentialité).
Rôle Solo, de bout en bout : cadrage, conception, développement, mise en production et marketing, sur 7 mois.
Ce que ça m'a appris Le produit tournait techniquement, mais j'ai sous-estimé l'acquisition. Construire n'est que la moitié du travail — j'ai depuis une vision beaucoup plus lucide de ce qu'exige le lancement d'un produit.

My Flashcards AI

Voir le site
Next.js API IA AWS S3
Problème Réviser à partir de longs documents PDF (cours, manuels) prend du temps et demande un effort de synthèse répétitif.
Ce que j'ai construit Une application qui génère automatiquement des flashcards à partir d'un PDF : le fichier est stocké temporairement dans un bucket S3, son contenu est extrait puis envoyé à une API IA qui génère les cartes de révision. Une fois les flashcards livrées à l'utilisateur, le PDF est supprimé définitivement.
Rôle Solo — conception du flux et intégration IA.
Point technique clé Un flux de stockage éphémère pensé par défaut pour la confidentialité : rien ne persiste au-delà de ce qui est strictement nécessaire à la génération.

My Special Calendar

Site en maintenance
Next.js Accès protégé par mot de passe
Origine Conçu au départ pour fêter un "moisniversaire" : un calendrier personnalisé où chaque jour cache une surprise différente — photo, musique, vidéo, mot doux ou cadeau à offrir en physique.
Ce que j'ai construit Un générateur de calendriers personnalisés et protégés par mot de passe, où chaque case peut contenir un type de contenu différent. Le concept se généralise facilement à d'autres usages, comme un calendrier de l'avent sur-mesure.
Rôle Solo — de l'idée personnelle à un produit réutilisable pour d'autres occasions.

Sports Tracker

iOS · React Native
React Native / Expo Node.js / Express PostgreSQL / Prisma JWT
Problème Suivre ses séances de sport et planifier son entraînement dans une application pensée pour son propre usage, avec la possibilité de suivre ses amis et de les inviter à des séances partagées.
Ce que j'ai construit Une application mobile iOS complète : activités et séances personnalisables, planification par date, statistiques, système d'amis complet — recherche par pseudo, demandes d'ami, suivi de leurs séances, et invitation à des séances partagées. Backend Node.js/Express avec base PostgreSQL hébergée sur Neon, déployé sur Render ; build et distribution iOS via EAS.
Point technique clé Un schéma de données volontairement flexible : chaque séance stocke ses champs sous forme de JSON, ce qui permet de définir n'importe quel type de sport sans rigidifier le modèle relationnel.
Rôle Solo — architecture mobile, backend et déploiement.
